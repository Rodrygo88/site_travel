# Jadoo Travel Landing Page

Landing page de viagens criada para praticar HTML e CSS a partir de um layout inspirado em um template do Figma.

O objetivo deste projeto foi treinar a construção de uma página visualmente mais completa, com várias seções, imagens, cards, botões, navegação e rodapé, usando apenas tecnologias base da web.

## Por que fiz este projeto?

Criei esta página como exercício de prática para evoluir na construção de interfaces. A ideia foi sair de layouts muito simples e trabalhar em uma página com cara de produto real, prestando atenção em espaçamento, hierarquia visual, organização dos elementos e fidelidade ao design original.

Também usei o projeto para praticar a leitura de um protótipo visual e transformar esse design em código, entendendo melhor como dividir uma página em seções reutilizáveis e como organizar os arquivos CSS.

## O que a página tem

- Cabeçalho com logo, menu de navegação e links de acesso
- Seção principal com chamada visual, botões e imagens
- Cards de serviços oferecidos
- Lista de destinos populares
- Bloco explicando o fluxo de reserva da viagem
- Área de depoimentos
- Seção de marcas/parceiros
- Campo de inscrição por e-mail
- Rodapé com links e redes sociais

## Aprendizados praticados

- Estruturação semântica com HTML5
- Organização de estilos em arquivos CSS separados
- Uso de Flexbox e Grid para posicionamento
- Criação de cards, botões, menus e seções
- Uso de imagens e ícones no layout
- Recriação de interface a partir de uma referência no Figma
- Atenção a espaçamentos, alinhamentos e hierarquia visual

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## Como visualizar

Abra o arquivo abaixo no navegador:

```text
travel-site/travel-site/index.html
```
